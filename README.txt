** KImulator Project Owner **
This drupal AI module is a project of Philipp Jorek of the impli informations-systeme GmbH

** Description **
The user can write a title and a prompt in a the form "kimulator/kiform" to create new with ai generatet content - especially a new node. Choose between the drupal standard nodes article and basic page.
The module uses an api of Openai. The user can choose between different models.

** Software **
This drupal module is for drupal 10 and 11, php 8.4

** Installation **
1. Download this git gepository in your drupal folder: modules/custom/kimulator
2. Create an ai key on the website of openai.com.
3. In Drupal go to your settings.php and set the key manually: $settings['set_apikey_openai'] = 'insertkeyhere';
